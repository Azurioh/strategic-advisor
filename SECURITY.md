# Security Policy

This repository contains prompt-only skills: no executable code runs on your machine when you install them. The only scripts (`scripts/`) are development helpers.

## Reporting a vulnerability

If you find a problem that could mislead users or expose them to harm (for example an instruction that could cause data exfiltration or unsafe tool use), please report it privately through [GitHub security advisories](https://github.com/Azurioh/strategic-advisor/security/advisories/new) rather than a public issue.

You can expect an acknowledgement within a week. Fixes are released as a patch version and noted in the [changelog](CHANGELOG.md).

## Supported versions

Only the latest release on `main` is supported.
